# Contributing to AUCTOR

We welcome contributions to AUCTOR! Whether it's reporting a bug, improving documentation, or adding new features, here is how you can help.

## Development Workflow
1. Fork the repository.
2. Create a feature branch: `git checkout -b feature/my-feature`.
3. Make your changes, ensuring you add tests for new functionality.
4. Run tests: `pytest`.
5. Submit a pull request.

## Principles
- **Minimalism**: Keep dependencies low and code simple.
- **Security First**: Ensure all new protocol changes are scrutinized against the threat model.
- **Verification**: New features must be independently verifiable.

Please ensure your code follows the existing style and passes all tests before submitting.
