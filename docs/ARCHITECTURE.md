# AUCTOR Architecture

AUCTOR uses a local-first, proof-carrying approach.
1. **Identity**: Ed25519 keypairs.
2. **Mandates**: Signed JSON-LD-like envelopes for authority delegation.
3. **Engine**: Stateless, deterministic validator.
4. **Receipts**: Hash-chained audit log of tool execution.
